 Sistema de Agendamento e Prontuário Odontológico

Cliente: Dr. Roberto (Sorriso Metálico)

Objetivo do Sistema:
Gerenciar agendamentos de consultas de alta performance com controle de prioridades e suporte a prontuário médico básico. O sistema automatiza a regra de exclusividade para atendimentos VIP aos sábados de manhã e permite a alocação de dentistas e acompanhamento do status das consultas.
